Uses the oreonhq/rpm-specfiles repository. For each package name, the specfile path will be <release-name>/<package>/<package>.spec (release name comes from the selected release).

Enter one or more package names (one per line or separated by spaces). A build will be triggered for each.

You list every package and stage yourself. Uses distgit spec paths like the DistGit tab. Colon : = parallel in one stage. Next stage starts after the previous stage is published. No colon = one package per stage in order. If a job in the current stage fails or is cancelled, the rest of that stage is cancelled. Fix specs and Resume with the chain id.

Resume from a previous chain

Starts a new chain with the same spec and picks up from the first stage that did not fully finish. Slots that already built and published in the old chain are not re-queued.
